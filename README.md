# MAT010 - Cálculo Integral

Para reconstruir eñ ambiente en otra máquina, puede reproducirlo como sigue:

## Conda

- Instalar conda
- Ejecutar
- `crear el proyecto a partir del repositorio https://github.com/jorgecueuk/mat010`
  - Desde IDEAJ crear el proyecto desde el repositorio
  - Desde fuera del IDE
    - `git clone https://github.com/jorgecueuk/mat010`
    - `cd mat010`
  - `conda create env -f environment.yml`
